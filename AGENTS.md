# Repository layout

The official course name is **DevOps in Practice**. Always use this exact name in every language.

Start every course presentation with a slide that greets the group, welcomes them to **DevOps in Practice**, and introduces the instructor by name.

Always create presentations as self-contained HTML experiences. Aim for exceptional visual design that surprises, inspires, and goes beyond conventional slide layouts. Break away from predictable grids, repetitive cards, boxed content, and generic templates. Think like a world-class creative director: use  visual storytelling and purposeful animations when they enhance the message. Every slide should feel deliberately crafted, not mechanically generated. Above all, embrace simplicity — reduce visual noise, communicate one clear idea at a time, and never sacrifice clarity for decoration. Be ambitious in creativity, minimalist in execution, and uncompromising in quality. The goal is not just to present information, but to make it memorable.

Keep the [course syllabus](course-syllabus.md) at the repository root. Edit it in place when updating the course outline.

Create course lessons in the `lessons/` directory at the repository root.

Don't modify AGENTS.md, README.md or course-syllabus.md if there is no explicit instruction from the user to do it.
