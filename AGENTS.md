# Presentations

Start every course lesson presentation with a slide that greets the group.

Always create presentations as self-contained HTML experiences. Aim for exceptional visual design that surprises, inspires, and goes beyond conventional slide layouts. Break away from predictable grids, repetitive cards, boxed content, and generic templates. Think like a world-class creative director: use  visual storytelling and purposeful animations when they enhance the message. Every slide should feel deliberately crafted, not mechanically generated. Above all, embrace simplicity — reduce visual noise, communicate one clear idea at a time, and never sacrifice clarity for decoration. Be ambitious in creativity, minimalist in execution, and uncompromising in quality. The goal is not just to present information, but to make it memorable.

Do not add buttons for "Next" or "Previous" controls, make it responsive to arrow keys.

Do not add slide numbers.

Colors: use graphite (#101317) as the background and warm white (#f1efe7) for primary text. Use sky blue (#7dd3fc) to highlight the concept being taught, turquoise (#5eead4) to mark a successful check, and yellow (#facc15) to draw attention to an unexpected result or a decision for the group. Give each slide at most one dominant accent and apply it to the specific word, value, or diagram element that deserves attention. Use a single neutral surface (#20252b) for code blocks and rely on spacing, alignment, and type size to keep the hierarchy clear when projected.
